# إضافة لوجوهات العملاء

ضع اللوجوهات هنا، ثم أضف بيانات كل عميل في clients-data.js في فولدر الموقع الرئيسي.

مثال داخل window.CLIENTS:
{ name: 'Client name', nameAr: 'اسم العميل', logo: 'assets/clients/client-name.png', theme: 'light' },

- استخدم SVG أو PNG بخلفية شفافة أو WebP. يفضّل دقة جيدة بدون مساحات فارغة كبيرة حول اللوجو.
- theme: 'light' خلفية فاتحة للوجوهات الداكنة والملونة؛ 'dark' خلفية داكنة للوجوهات البيضاء.
- لا يتم قص اللوجوهات أو تغيير ألوانها.
- المساحات المؤقتة تختفي تلقائيًا بمجرد إضافة أول عميل.
- الشريط يتحرك باستمرار ويكرر المجموعة بسلاسة. يوجد زر لإيقاف واستئناف الحركة.
- إذا الزائر مفعّل تقليل الحركة في جهازه، يمكنه بدء الحركة يدويًا.
- لا تضع مسارًا مثل C:\...؛ استخدم المسار النسبي assets/clients/filename.png.

إذا أرسلت ملفًا مجمعًا باللوجوهات، يمكن استخراجها وتجهيزها وربطها بالموقع.
